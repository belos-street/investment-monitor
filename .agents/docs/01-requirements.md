# 01 - 结构化需求工程

> 投资监控工具的正式 PRD

---

## 1. 项目概述

### 1.1 定位

| 维度 | 描述 |
|------|------|
| 产品形态 | PC/Mac 桌面托盘小工具 |
| 目标用户 | 价值投资者、定投用户、没时间盯盘的上班族 |
| 核心价值 | 只做提醒，不做交易 |
| 设计理念 | 极简、专注、无干扰 |

### 1.2 一句话描述

> 一个运行在系统托盘的轻量桌面工具，用户添加关注的 A 股/ETF 标的并配置提醒规则，工具自动定时轮询行情数据，条件触发时弹出系统通知。

### 1.3 核心设计约束

| 约束 | 说明 |
|------|------|
| 无后端服务 | 所有逻辑在本地运行，不依赖云服务 |
| 不涉及交易 | 只监测行情和指标，不做任何交易操作 |
| 不涉及社交 | 无社区、无新闻推送、无分享功能 |
| 数据本地化 | 持仓和规则存储在本地，不上传云端 |

## 2. 功能模块划分

### 2.1 模块总览

| 模块 | 职责 | 技术实现层 |
|------|------|-----------|
| 持仓管理 | 标的增删、导入导出 | Rust Command + 前端 UI |
| 数据监测 | 行情轮询、指标采集 | 前端 stock-sdk 直连 |
| 规则引擎 | 条件匹配、触发判断 | 前端逻辑 |
| 通知服务 | 系统通知弹出 | Rust Command（Tauri 原生通知） |
| 设置管理 | 更新频率、通知开关 | Rust Command + 前端 UI |

### 2.2 优先级划分

**P0（MVP 必须）：**
- A 股/ETF 标的添加（搜索 + 手动输入）
- 实时行情轮询（价格、PE、PB、股息率、涨跌幅）
- 单条件规则配置（价格、PE、PB、股息率、涨跌幅）
- 规则匹配与系统通知
- 系统托盘常驻 + 主窗口弹出
- 持仓和规则本地持久化

**P1（后续迭代）：**
- 组合规则（AND/OR）
- 声音提醒
- 通知历史
- 港股支持
- 开机自启动

## 4. 正常流程

### 4.1 添加标的

```
用户输入代码 → 调用 sdk.search() → 展示结果 → 用户确认
    → 调用 invoke('add_portfolio', ...) → 写入 tauri-plugin-store → UI 刷新列表
```

### 4.2 行情监测循环

```
启动定时器（交易时间每 30s）
    → 收集所有持仓代码
    → 调用 sdk.quotes.cn() / sdk.quotes.fund() 批量查询
    → 更新 UI 表格数据
    → 遍历活跃规则，逐条匹配
    → 匹配成功 → 检查触发策略（单次触发 / 条件复位）
    → 满足触发条件 → 调用 invoke('send_notification', ...)
```

### 4.3 规则触发（单次触发 + 条件复位）

```
当前值 vs 阈值比较
    → 条件从 false 变 true → 触发通知，记录 lastTriggeredAt
    → 条件仍为 true → 跳过（不重复触发）
    → 条件恢复为 false → 标记已复位，下次 true 时可再次触发
```

## 5. 异常流程

| 场景 | 处理方式 |
|------|----------|
| stock-sdk 请求失败 | 静默重试 3 次，间隔递增；全部失败后状态栏显示「数据获取失败」 |
| stock-sdk 返回空数据 | UI 对应字段显示 `-`，不触发规则匹配 |
| 用户输入无效代码 | 搜索结果为空时提示「未找到匹配标的」 |
| YAML 导入格式错误 | 提示「配置文件格式错误」，不写入任何数据 |
| YAML 导入与现有数据冲突 | 覆盖写入（以导入文件为准），导入前提示用户 |
| 通知权限被拒绝 | 状态栏提示「通知权限未开启，请在系统设置中开启」 |
| 存储文件损坏/不存在 | 使用空数据初始化，不影响应用运行 |
| 非交易时间启动 | 不发起数据请求，显示上次缓存数据（如有） |

## 6. 边界场景

| 场景 | 处理方式 |
|------|----------|
| 持仓数量为 0 | 主界面显示空状态提示「暂无持仓，点击添加标的」 |
| 持仓超过 100 个 | 批量查询分批进行（stock-sdk 内置限流），UI 虚拟滚动 |
| 规则阈值为空/非法 | 表单校验，不允许保存 |
| 同一标的添加两次 | 检查 code + market 唯一性，提示「已存在」 |
| 涨跌幅规则值输入 50% | 合法输入，但二次确认「涨跌幅 50% 较大，确认保存？」 |
| 开机后无网络 | 静默失败，状态栏显示「网络不可用」，有网后自动恢复 |
| 关闭窗口时有未保存规则 | 提示保存确认 |

## 7. 验收标准（DoD）

### 7.1 MVP 完成标准

- [ ] 启动应用后只显示系统托盘图标，主窗口默认隐藏
- [ ] 点击托盘图标弹出主窗口，点击窗口外自动隐藏
- [ ] 右键托盘图标弹出快捷菜单（显示/暂停/设置/退出）
- [ ] 输入代码可搜索 A 股和 ETF，确认后添加到持仓列表
- [ ] 主界面表格实时显示：代码、名称、实时价、涨跌幅
- [ ] 股票额外显示 PE、PB、股息率；ETF 对应列显示 `-`
- [ ] 交易时间每 30 秒自动刷新行情数据
- [ ] 非交易时间不发起数据请求
- [ ] 可为每个标的配置单条件规则（价格/PE/PB/股息率/涨跌幅）
- [ ] 规则触发时弹出系统通知（Tauri 原生通知）
- [ ] 同一条件不重复触发（单次触发 + 条件复位策略）
- [ ] 持仓和规则数据持久化到 tauri-plugin-store
- [ ] 支持 YAML 格式导出/导入完整配置
- [ ] 应用启动时间 < 2 秒，内存占用 < 100MB
- [ ] macOS 和 Windows 均可正常运行

### 7.2 不在 MVP 范围内（明确排除）

- 组合规则（AND/OR）
- 声音提醒
- 通知历史列表
- 港股行情
- 开机自启动
- 用户账户/登录
- 云端同步
