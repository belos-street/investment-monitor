# 📊 Investment Monitor - 价值投资者智能监控助手

> **不做交易，只做提醒** | 让价值投资者告别盯盘焦虑

***

## 一、项目概述

### 1.1 项目背景

价值投资者的核心理念是"长期持有、分红再投入"，但现实中常常面临一个矛盾：

- **理念上**：应该忽略短期波动，专注长期价值
- **行为上**：忍不住每天盯盘，焦虑涨跌，影响工作生活

**Investment Monitor** 旨在解决这个痛点：通过自动化监测和智能提醒，让投资者"设置完就忘"，只在关键时机收到通知，从而真正做到"做时间的朋友"。

### 1.2 产品定位

| 维度       | 描述                   |
| -------- | -------------------- |
| **产品类型** | PC/Mac 桌面小部件（Widget） |
| **目标用户** | 价值投资者、长期持有者、定投用户     |
| **核心价值** | 自动监测 + 智能提醒 = 告别盯盘   |
| **产品理念** | 极简、专注、无干扰            |

### 1.3 差异化优势

| 竞品         | 缺点        | 我们的优势        |
| ---------- | --------- | ------------ |
| 同花顺/东方财富   | 功能复杂，容易沉迷 | 只做提醒，不做交易    |
| 雪球         | 推送多，社区干扰  | 无社区，无新闻，专注数据 |
| Excel 手动记录 | 需要手动更新    | 自动化，实时监测     |
| 自己写脚本      | 需要编程能力    | 可视化配置，零代码    |

## 四、详细功能设计

### 4.1 持仓管理

#### 4.1.1 添加标的

```
┌─────────────────────────────────────────┐
│  ➕ 添加新标的                            │
├─────────────────────────────────────────┤
│  代码: [________________] [查询]         │
│                                          │

│  ┌───────────────────────────────────┐  │
│  │ 515450 红利低波50ETF              │  │

│                                          │

```

**支持的标的类型**：

- A股股票（如：600036 招商银行）
- ETF基金（如：515450 红利低波ETF）
- 场外基金（如：006493 南方中债3-5年农发债）
- 港股（如：0941 中国移动）

#### 4.1.2 持仓列表

| 字段   | 说明          |
| ---- | ----------- |
| 代码   | 股票/基金代码     |
| 名称   | 标的名称        |
| 类型   | 股票/ETF/基金   |
| 最新价  | 实时价格        |
| 涨跌幅  | 今日涨跌幅       |
| PE   | 市盈率（股票/ETF） |
| PB   | 市净率（股票/ETF） |
| 股息率  | 近12个月股息率    |
| 持仓成本 | 用户手动输入      |
| 持仓数量 | 用户手动输入      |
| 盈亏   | 自动计算        |

#### 4.1.3 持仓导入导出

支持 YAML 格式的持仓数据导入导出：

```yaml
# portfolio.yaml 格式示例
portfolio:
  - code: "515450"
    name: "红利低波50ETF"
    type: "ETF"
    cost: 1.35
    quantity: 10000
  - code: "600036"
    name: "招商银行"
    type: "股票"
    cost: 35.50
    quantity: 1000
```

**功能说明**：
- **导出**：将当前持仓数据导出为 YAML 文件，方便备份和分享
- **导入**：从 YAML 文件导入持仓数据，支持增量更新和覆盖模式

### 4.3 规则引擎

#### 4.3.1 规则类型

| 规则类型      | 说明      | 示例               | 实现难度 |
| --------- | ------- | ---------------- | -------- |
| **价格规则**  | 价格触发    | 价格 ≤ 1.35元       | 简单 |
| **估值规则**  | PE/PB触发 | PE ≤ 10倍         | 简单 |
| **股息率规则** | 股息率触发   | 股息率 ≥ 5%         | 简单 |
| **涨跌幅规则** | 涨跌幅触发   | 单日跌幅 ≥ 3%        | 简单 |
| **均线规则**  | 均线触发    | 跌破60日均线          | 中等 |
| **组合规则**  | 多条件组合   | PE≤10 AND 股息率≥5% | 中等 |

**实现说明**：
- **涨跌幅规则**：实现简单，API通常直接提供涨跌幅数据，或通过 `(当前价 - 昨收) / 昨收` 计算
- **均线规则**：需要获取历史数据，计算N日均线。需要存储一定天数的历史收盘价，实现复杂度中等

### 5.4 数据库设计

#### 5.4.1 持仓表 (portfolios)

```sql
CREATE TABLE portfolios (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  code TEXT NOT NULL,           -- 代码 (如: 515450)
  name TEXT NOT NULL,           -- 名称
  type TEXT NOT NULL,           -- 类型: stock/fund/etf
  market TEXT,                  -- 市场: sh/sz/hk
  cost_price REAL,              -- 持仓成本
  quantity INTEGER,             -- 持仓数量
  target_ratio REAL,            -- 目标占比
  memo TEXT,                    -- 备注
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### 5.4.2 监测数据表 (market\_data)

```sql
CREATE TABLE market_data (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  code TEXT NOT NULL,
  price REAL,                   -- 最新价格
  change_pct REAL,              -- 涨跌幅
  pe REAL,                      -- 市盈率
  pb REAL,                      -- 市净率
  dividend_yield REAL,          -- 股息率
  volume REAL,                  -- 成交量
  timestamp DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### 5.4.3 规则表 (rules)

```sql
CREATE TABLE rules (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  portfolio_id INTEGER,         -- 关联持仓
  name TEXT NOT NULL,           -- 规则名称
  type TEXT NOT NULL,           -- 规则类型
  conditions TEXT NOT NULL,     -- 条件 (JSON)
  actions TEXT NOT NULL,        -- 动作 (JSON)
  is_active BOOLEAN DEFAULT 1,  -- 是否启用
  last_triggered_at DATETIME,   -- 最后触发时间
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (portfolio_id) REFERENCES portfolios(id)
);
```

#### 5.4.4 通知记录表 (notifications)

```sql
CREATE TABLE notifications (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  rule_id INTEGER,
  portfolio_id INTEGER,
  type TEXT NOT NULL,           -- 类型: buy/sell/alert
  message TEXT NOT NULL,        -- 通知内容
  current_value REAL,           -- 触发时的值
  is_read BOOLEAN DEFAULT 0,    -- 是否已读
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (rule_id) REFERENCES rules(id),
  FOREIGN KEY (portfolio_id) REFERENCES portfolios(id)
);
```
