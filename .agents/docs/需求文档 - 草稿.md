# 📊 Investment Monitor - 价值投资者智能监控助手

> **不做交易，只做提醒** | 让价值投资者告别盯盘焦虑

***

## 一、项目概述

### 1.1 项目背景

价值投资者的核心理念是"长期持有、分红再投入"，但现实中常常面临一个矛盾：

- **理念上**：应该忽略短期波动，专注长期价值
- **行为上**：忍不住每天盯盘，焦虑涨跌，影响工作生活

**Investment Monitor** 旨在解决这个痛点：通过自动化监测和智能提醒，让投资者"设置完就忘"，只在关键时机收到通知，从而真正做到"做时间的朋友"。

### 1.2 产品定位

| 维度       | 描述                   |
| -------- | -------------------- |
| **产品类型** | PC/Mac 桌面小部件（Widget） |
| **目标用户** | 价值投资者、长期持有者、定投用户     |
| **核心价值** | 自动监测 + 智能提醒 = 告别盯盘   |
| **产品理念** | 极简、专注、无干扰            |

### 1.3 差异化优势

| 竞品         | 缺点        | 我们的优势        |
| ---------- | --------- | ------------ |
| 同花顺/东方财富   | 功能复杂，容易沉迷 | 只做提醒，不做交易    |
| 雪球         | 推送多，社区干扰  | 无社区，无新闻，专注数据 |
| Excel 手动记录 | 需要手动更新    | 自动化，实时监测     |
| 自己写脚本      | 需要编程能力    | 可视化配置，零代码    |

## 四、详细功能设计

### 4.1 持仓管理

#### 4.1.1 添加标的

```
┌─────────────────────────────────────────┐
│  ➕ 添加新标的                            │
├─────────────────────────────────────────┤
│  代码: [________________] [查询]         │
│                                          │
│  查询结果:                                │
│  ┌───────────────────────────────────┐  │
│  │ 515450 红利低波50ETF              │  │

│                                          │
│  [取消]  [添加到持仓]                     │
└─────────────────────────────────────────┘
```

**支持的标的类型**：

- A股股票（如：600036 招商银行）
- ETF基金（如：515450 红利低波ETF）

#### 4.1.2 持仓列表（主界面）

简洁表格设计，显示核心信息：

| 字段   | 说明          |
| ---- | ----------- |
| 代码   | 股票/基金代码     |
| 名称   | 标的名称        |
| 实时价格 | 实时价格        |
| PE   | 市盈率（股票/ETF） |
| PB   | 市净率（股票/ETF） |
| 股息率  | 近12个月股息率    |

#### 4.1.3 持仓导入导出

支持 YAML 格式的持仓数据导入导出：

```yaml
# portfolio.yaml 格式示例
portfolio:
  - code: "515450"
    name: "红利低波50ETF"
    type: "ETF"
    cost: 1.35
    quantity: 10000
  - code: "600036"
    name: "招商银行"
    type: "股票"
    cost: 35.50
    quantity: 1000
```

**功能说明**：
- **导出**：将当前持仓数据导出为 YAML 文件，方便备份和分享

### 4.2 数据监测

#### 4.2.1 监测指标

| 指标          | 适用标的   | 数据来源    |
| ----------- | ------ | ------- |
| **实时价格**    | A股/ETF | stock-sdk |
| **PE（市盈率）** | A股/ETF | stock-sdk |
| **PB（市净率）** | A股/ETF | stock-sdk |
| **股息率**     | A股/ETF | stock-sdk |
| **涨跌幅**     | A股/ETF | stock-sdk |

#### 4.2.2 数据更新频率

| 时间段              | 更新频率    | 说明    |
| ---------------- | ------- | ----- |
| 交易时间（9:30-15:00） | 每30秒    | 实时监测  |
| 盘前盘后             | 每5分钟    | 关注异动  |
| 非交易时间            | 不更新     | 节省资源  |

#### 4.2.3 数据来源

使用 `stock-sdk` 库作为统一数据接口，支持 A 股和 ETF 的实时行情、估值指标等数据。

**stock-sdk 优势**：
- 专业的股票数据 SDK，接口稳定
- 支持批量查询，性能优化
- 内置重试、限流、熔断机制
- 统一的数据格式，便于处理

**示例代码**：
```typescript
import { StockSDK } from 'stock-sdk';

const sdk = new StockSDK({
  rateLimit: { requestsPerSecond: 5 },
  retry: { maxRetries: 3 }
});

// 获取实时行情（含 PE、PB 等）
const quotes = await sdk.getFullQuotes(['sh600036', 'sz515450']);
```

### 5.3 数据存储方案

**推荐方案：JSON 文件存储**

对于本项目的简单数据结构，使用 JSON 文件是最轻量的方案：

**优点**：
- 无需额外依赖，Node.js 原生支持
- 人类可读，方便手动编辑和备份
- 与 YAML 导出功能天然契合
- 适合小数据量（持仓通常 < 100 条）

**存储结构**：
```
~/.investment-monitor/
├── portfolio.json      # 持仓数据
├── rules.json          # 提醒规则
└── notifications.json  # 通知历史
```

**对比其他方案**：

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **JSON 文件** | 简单、无依赖、可读性好 | 不适合复杂查询 | ✅ 本项目 |
| SQLite | 支持复杂查询、性能好 | 需要额外依赖 | 数据量大、需要复杂查询 |
