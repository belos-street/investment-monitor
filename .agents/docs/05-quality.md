# 05 - 质量测试

---

## 1. 测试策略

本项目为个人浏览器扩展工具，采用**手动测试为主**的策略，覆盖核心功能路径和关键边界场景。

| 测试类型 | 覆盖范围 | 执行方式 |
|----------|----------|----------|
| 功能测试 | 所有 P0 功能 | 手动 |
| 边界测试 | 空值、极限值、非法输入 | 手动 |
| 异常测试 | 网络断开、存储损坏、权限拒绝 | 手动 |
| 兼容性测试 | Chrome + Edge | 手动 |
| 性能验证 | Popup 打开时间、Service Worker 启动时间、内存占用 | 手动观察 |
